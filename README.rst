Braincoder
==========

**Braincoder** is a package to fit encoding models to neural data (for now fMRI) and
to then *invert* those models to decode stimulus information from neural data. It runs on
TensorFlow, JAX or PyTorch through Keras 3.

- Documentation: https://braincoder-devs.github.io/
- Source code: https://github.com/Gilles86/braincoder
- Installation: https://braincoder-devs.github.io/installation.html
